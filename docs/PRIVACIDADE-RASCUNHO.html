Política de Privacidade

Rascunho para validação: os itens marcados como pendentes precisam ser confirmados pelos responsáveis antes da publicação.

Quais dados usamos nesta etapa

  • E-mail e senha: para localizar a conta e verificar o acesso. A senha é comparada com um hash bcrypt guardado no sistema; não fica armazenada em texto simples.
  • Dados da sessão: identificador da conta, nome e perfil para manter o acesso e aplicar as permissões correspondentes. A sessão tem validade limitada; scripts da página não podem ler o cookie e, em produção, o navegador só o envia por HTTPS.
  • Endereço IP: usado temporariamente, em memória, para limitar tentativas automatizadas de login.

Para que são usados

Esses dados permitem autenticar usuários cadastrados, manter a sessão enquanto usam o sistema e restringir as funções conforme o perfil atribuído. O login não pede consentimento como condição de acesso.
