# Interface quality requirements

- Whenever a module is created, edited, or added, review its layout at desktop and mobile widths before calling the work complete or publishing it.
- Align page titles, section titles, form labels, and the top edges of controls across a row. Helper text, textareas, and file inputs must not shift neighboring fields out of alignment.
- Reuse the shared form grid, card, heading, and spacing styles. Avoid one-off offsets that make similar modules inconsistent.
- Check for clipped content, horizontal overflow, overlapping controls, and uneven card or title alignment in the affected module.
- Bundle pending application changes into the same publication so the deployed version contains the complete set of requested updates.
